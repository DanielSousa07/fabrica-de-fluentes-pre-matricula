# 🚀 Fábrica de Fluentes - Landing Page

Uma Landing Page de alta conversão desenvolvida para um curso de inglês, focada em experiência do usuário (UX/UI), design moderno com tema escuro e efeitos em neon vermelho, componentização limpa e alta performance.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando as melhores práticas do ecossistema front-end moderno:
* **React** (com Vite para alta performance de build e HMR)
* **CSS Modules** (para escopo isolado de estilos e organização modular)
* **JavaScript (ES6+)**
* **SVG Icons & Responsive Design**

## ✨ Funcionalidades

* **Seção Hero de Alto Impacto:**
  * Logotipo customizado com tipografia de alto contraste.
  * Título persuasivo com destaque visual em neon.
  * Lista de benefícios com marcadores interativos.
  * Formulário de captura de leads estruturado (Nome, E-mail e Telefone com DDI).
* **Seção de Depoimentos Interativa:**
  * Grid responsivo integrando vídeos incorporados do YouTube.
  * Cards customizados com depoimentos reais de alunos, fotos e player de vídeo dinâmico.
* **Design System & Responsividade:**
  * Paleta de cores dark otimizada com gradientes e sombras em vermelho escuro.
  * Layout totalmente responsivo para dispositivos móveis e desktops.
